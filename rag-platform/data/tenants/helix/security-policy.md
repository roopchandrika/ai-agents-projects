# Helix Information Security Policy

Experimental data must be recorded in Benchling, never in personal notebooks or spreadsheets. Patient-derived
data is stored only in the validated LIMS and may not be exported without a data use agreement.

Accounts use Microsoft Entra ID with number-matching MFA. USB storage is blocked on all lab computers.

Suspected data exposure must be reported to the security team within one hour so the privacy officer can assess
regulatory reporting duties.
