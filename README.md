# ai-agent-projects

Three small, independently runnable Claude/Anthropic projects:

- [`rag_pdfs`](./rag_pdfs) — RAG chatbot over PDFs (chunking, TF-IDF embeddings, Chroma, cited answers).
- [`langgraph_router`](./langgraph_router) — LangGraph-based support-ticket classifier/router.
- [`function_calling_agent`](./function_calling_agent) — a hand-rolled tool-use loop on the Anthropic API (no framework).

Each subfolder has its own `README.md`, `requirements.txt`, and `.env.example`. See each project's README for setup and usage.
